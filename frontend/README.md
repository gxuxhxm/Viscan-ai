# Viscan AI — Frontend

React 19 + Vite + Tailwind CSS v4 client for Viscan AI.

```powershell
npm install
npm run            # list scripts (dev, build, lint, test, preview)
npm run dev        # → http://localhost:5173 (API: http://localhost:8000)
npm test           # 27 vitest tests
```

Full setup, features, API and limitations: see the [root README](../README.md) · Architecture: [ARCHITECTURE.md](../ARCHITECTURE.md)
